Pair your phone

How to pair

On your PC, press PAIR MY PHONE. Scan the code with your iPhone Camera, then tap Open in “SwipeLater”.

Stuck? Use the same Wi-Fi on both. Codes expire after a few minutes, so press NEW CODE for another.

Step 3 of 4 · Optional

Connect your browser

Lets your buddy see when scrolling takes over. You can skip this.

  1. 1In SwipeLater, press CONNECT BROWSERS. Chrome opens Extensions.
  2. 2Turn on Developer mode, top right.
  3. 3Press Load unpacked.
  4. 4Click the folder box, press Ctrl V, then Select Folder.
  5. 5On SwipeLater buddy, press Details and turn on Allow in Incognito.

Stuck? No Developer mode switch? The address should read chrome://extensions (or edge://extensions in Edge).
